# 解耦 GraphRAG 图检索与图谱抽取生命周期

状态：已接受（2026-07-24）

数据集保留“启用 GraphRAG”作为图检索开关，并新增独立的“启用图谱抽取/索引”开关及其模型、Schema、属性和抽取参数配置。抽取配置按普通文档范围或 Knowledge Base 节点范围独立版本化：节点首次启用时取得数据集模板快照，之后不自动同步；影响抽取结果的保存采用最新配置优先的异步重建，先清理该范围旧图数据且不保留回退。图检索按范围降级，只使用已就绪图数据，以避免抽取开关、模型失效或重建中的数据造成跨范围阻断或静默使用旧数据。

## 考虑过的方案

- 将“启用 GraphRAG”继续同时代表图检索与图谱抽取：拒绝，两个能力的生命周期、失败语义和用户操作不同。
- 修改数据集模板时自动覆盖所有节点：拒绝，节点配置必须是可独立维护的初始快照。
- 保留旧版本图数据直到新版本成功：拒绝，用户选择配置生效后立即删除受影响范围的旧结果，避免查询到与当前 Schema 或模型不一致的图数据。
