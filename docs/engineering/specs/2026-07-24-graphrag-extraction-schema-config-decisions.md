# GraphRAG 图谱抽取 Schema 默认值与配置决策记录

- 日期：2026-07-24
- 状态：已确认，作为后续 `to-spec` 的输入，不替代完整实现规格。
- 上游约束：`2026-07-16-graphrag-raw-requirements.md`、`2026-07-23-knowledge-base-graph-attribute-config-spec.md` 与上游 fork 兼容要求仍然有效；若旧规格与本记录冲突，以本记录的新增决策为准。

## 已确认的产品边界

1. 数据集设置中的“启用 GraphRAG”仅表示**启用图检索**，说明文案不得再暗示其会启动 LlamaIndex 图抽取。
2. 数据集设置新增独立的**启用图谱抽取/索引**开关和模板配置区域；该区域承载抽取模型、完整图谱 Schema、实体/关系属性及抽取高级参数。
3. 图检索与图谱抽取/索引独立保存、独立生效。关闭图检索不删除图数据；关闭抽取/索引会停止该范围后续抽取、立即删除该范围图数据并使其不再参与图检索。
4. Knowledge Base 节点只承载图谱抽取/索引配置，正式字段仍为 `graph_index_config`，不得新增 `graph_rag_config` 别名，也不得把图检索运行参数放入节点 DSL。

## 默认模板与配置所有权

1. 第一次在数据集启用图谱抽取/索引时，系统用内置通用文档 Schema 预填可编辑草稿；默认值是初始赋值，不建立持续继承或自动同步。
2. 内置默认 Schema：
   - 实体类型：`person`、`organization`、`location`、`event`、`concept`。
   - 关系类型：`works_for`、`located_in`、`participates_in`、`related_to`。
   - 允许三元组：`person-works_for-organization`、`person-located_in-location`、`organization-located_in-location`、`person-participates_in-event`、`organization-participates_in-event`、`organization-related_to-organization`、`concept-related_to-concept`。
   - 默认不预置自定义实体属性或关系属性；属性能力和既有节点级属性规格完全一致。
3. 第一次启用时，用户必须从当前租户中已配置且可用的模型中显式选择抽取模型；系统不得自动选择“第一个可用模型”。
4. 模板与节点均支持模型、`temperature`、`max_tokens`、`max_triplets_per_chunk` 和 `strict`；首次启用沿用现有安全默认值。本次不提供自定义 LlamaIndex 图抽取 Prompt。
5. 新启用的 Knowledge Base 节点复制当时的数据集模板为自身初始 `graph_index_config`。节点保存后独立维护；以后修改数据集模板不回写已有节点。
6. 数据集模板适用于普通文档；Pipeline 节点显式存在 `graph_index_config` 时该配置是唯一抽取配置。历史 Pipeline 节点缺少该字段时，保留数据集级既有行为，以兼容存量 DSL。

## 启用、模型失效与校验

1. 未启用状态可保存不完整草稿。真正启用图谱抽取/索引或图谱索引时，必须同时满足：已选可用模型、至少一个实体类型、至少一个关系类型，以及至少一个引用已声明类型的有效允许三元组。
2. 校验失败时，保持未启用状态并返回字段级错误；不得创建图谱版本或投递重建。
3. 已保存抽取模型后来不可用时，不自动换模，不删除已经建成且就绪的图数据。已有数据可继续被图检索使用；新增抽取、重建或任何影响抽取结果的配置变更必须阻止并提示用户重新显式选择可用模型。

## 版本、删除与重建

1. 首次启用抽取/索引，或修改模型、Schema、属性定义、允许三元组和其他影响抽取结果的参数时，生成新的稳定图谱版本，并异步、分批重建受影响的历史文档。页面不等待任务完成，应显示状态。
2. 保存新版本后立即删除受影响范围的旧版图数据，不保留查询回退；普通文档范围与每个 Knowledge Base 节点范围必须严格隔离，禁止误删其他节点、其他文档或其他版本范围的数据。
3. 同一普通文档范围或同一节点范围的重建互斥。用户再次保存新配置时，旧任务必须失效，清理该范围旧版和中间数据，只调度最新版本任务；流程应可幂等重试。
4. 旧图数据已删而新版本重建中或失败时，该范围不参与图检索。用户修正配置后可再次重建；向量检索和其他知识库能力持续可用。
5. 数据集图检索按范围降级：只使用已就绪的普通文档范围及节点范围图数据；重建中或失败范围跳过，页面展示各范围状态及“图检索结果可能不完整”的提示。

## 明确覆盖的旧规格条款

本记录覆盖 `2026-07-23-knowledge-base-graph-attribute-config-spec.md` 中以下与新增需求冲突的旧边界：

- “将数据集级 GraphRAG 配置自动复制到节点级配置”仍然禁止为持续同步；但**新启用节点的一次性初始模板复制**现为明确要求。
- “禁用节点图谱配置时删除已有图数据”不再属于排除范围；本记录要求关闭抽取/索引时立即删除该受影响范围数据。
- “改造现有数据集级 GraphRAG 功能”不再整体排除；仅允许为本记录定义的图检索/图谱抽取开关解耦、模板及状态呈现做最小必要调整，既有检索运行参数、排序和向量检索行为仍不在范围内。
